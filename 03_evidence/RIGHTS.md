# Rights, local copies and reuse

This local collection does not apply a blanket license to third-party materials. Source code licenses already present in each Rust project and the Marsden author-data MIT notice remain authoritative for those components. PLOS soil/article supplements retain their CC BY attribution. APSIM-related examples retain their original source/licensing context; the independent Rust model is not official APSIM or a verified equivalent implementation.

User-provided papers, publisher PDFs, extension bulletins, seed catalogues, news/web snapshots and the AAEA conference paper are retained for local research and audit. Their inclusion is not permission for unrestricted republication. The AAEA PDF retains its noncommercial-copy notice. Government-origin datasets, university publications and commercial catalogues should not be assumed to share one license. Consult the original provider and retained source URL before external redistribution.

No credentials, signed-in browser profiles, dependency vendors or toolchain caches are intended for this collection. OAuth client IDs, public project identifiers and localhost callback code in source are configuration/program logic, not a supplied authorization environment. Do not commit runtime secrets or populated credential files in future work.
