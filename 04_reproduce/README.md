# 最小复现范围

从本目录运行 `python3 -m pip install -r requirements.txt`，安装 Rust/Cargo 和 C 链接器后，运行 `python3 run.py`。模型不依赖外部 Cargo crates，不需要 GPU、APSIM 或 Google 授权。

本目录只保留最新田块诊断、真实试验重分析及其必要相对路径依赖。运行输出写在本目录下，主汇报和 `03_evidence` 保持冻结。田块诊断保留全部 32 次设定组合，不能挑最优组作为已验证参数。县域历史全量实验和全国筛查的完整获取流程不在此最小运行入口中，必要时查阅 `../../repo`。

源码仍包含部分历史作者路径和平台元数据；主 runner 能使用系统 cargo，Mac SDK 仅在已存在时覆盖。现成输出的二进制散列不要求跨编译器一致；数值和输入来源才是复核对象。
