# Field Shift｜同行交流与汇报材料

本包只保留一套当前结论和展示材料。研究主题是利用 NASA 环境数据、本地农艺信息与农户约束，支持轮作方案讨论。**当前成果是证据审计与决策支持；尚无通过验证的最佳轮作、农户产量／利润／节水预测或推荐排名。**

## 建议阅读顺序

1. [研究简报](01_briefing/Research_Brief_CN.md)：背景、研究问题、方法、最终结果与局限。
2. [汇报幻灯片](01_briefing/Research_Briefing_EN.pptx)：约 12–15 分钟，英文正文；每页附来源与讲述说明。
3. [讲述提纲](01_briefing/Speaker_Notes_CN.md)：中文交流主线和演示顺序。
4. [演示入口](02_demo/index.html)：当前农户工具、真实试验证据与最新记录核验。

## 内容分层

|目录|用途|不包含什么|
|---|---|---|
|`01_briefing`|一份研究简报、一份当前汇报稿、一份讲述提纲|旧 proposal、旧汇报稿、候选方案排名|
|`02_demo`|一个演示入口和当前应用|多个原型、过时故事页、未验证的预测界面|
|`03_evidence`|支持主张的最终评估表、必要方法依据与引用|全部试跑、所有来源 URL、重复打包|
|`04_reproduce`|最新田块回放与真实试验重分析的最小代码和输入|早期校准网格、工具链、依赖 vendor、编译缓存|

“最终”按来源可追溯、单位和范围正确、评估协议明确、结论边界完整选取，**没有挑误差最小的参数组合冒充验证结果**。32 次田块诊断保留全部假设组合，因为它们共同决定不确定性范围。历史技术包的经济顺序仅用于说明条件性，不作为推荐。

## 如何演示

在 `repo2` 目录运行：

```sh
python3 -m http.server 8817
```

浏览器打开 `http://127.0.0.1:8817/02_demo/`。先选农户约束，再看真实试验证据，最后展示记录核验中的未闭合门槛。应用的保存仅在浏览器本地；真实农户可用性测试参与者仍为 0。

## 如何追问依据

从 [证据导航](03_evidence/README.md) 查找 E1–E7。主结果表直接保留 CSV/JSON，可计算复核；原始记录、来源回执与独立 Rust 源码放在复现目录。NASA 区域气象不等于田块实测，县级产量不等于逐田管理验证。

完整研究档案仍在 `../repo`；本目录用于交流，不重复历史档案。第三方许可与本地研究原件边界见 `03_evidence/RIGHTS.md`。
